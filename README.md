# Service_Monitor
Using a Raspberry Pi Zero 2W to monitor services on a separate Raspberry Pi 5. It will include a 2.0" TFT OLED and a rotary encoder to visually manipulate what is being shown on the screen. 
There will also be a button to select options for each service, such as restarting a service, showing detailed logs, etc.
The Pi5 will also be monitored and will include a reboot option as well.
